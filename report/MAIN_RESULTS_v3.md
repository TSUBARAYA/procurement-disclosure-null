# NEO v3.0 主结果（合同级采购数据：TED CAN）

版本 v3.0.0 | 种子 20261018 | 数据：EU Open Data TED 合同授标公告，EU-28，2013-2021，
**6,782,760 份合同**（阈值稳定子样本 946,234 份），252 个 country-year。

## 一、总结论

**改革的数字化机制被切实执行（第一阶段强），但 2-3 年内没有任何竞争指标改善；
均值类竞争指标方向为负（缩尾后仍显著），证据等级弱到中等。**

## 二、第一阶段：电子投标份额（改革机制的直接度量）

- ATT（事件后 2-3 年）= **+0.382**（全样本）/ **+0.431**（阈值稳定样本，
  CI [0.151, 0.574]，排除 0）
- 事件动态：et−2 = +0.001（事前干净）→ et0 = +0.05 → et+2 = +0.30 →
  et+3 = +0.41 → et+4 = +0.65 → et+6 = +0.86
- 事前趋势 p = 0.83 / 0.32

→ 2014/24/EU 的国内转化确实把采购流程数字化了。第一阶段成立。

- **没有任何指标显示竞争改善**

合同级数据把测量精度提高 3.2 倍，但识别变异仍是国家级的（28 国、后期队列
对照薄），不足以把 MDE 打到效应量级以下。

## 五、混淆排除

1. **组成漂移**：全样本中合同数九年翻倍、中位合同金额下降（小额公告增多），
   但阈值稳定样本（高于各年 EU 阈值）结论不变 → +0.032 不是组成假象
2. **类型结构**：九年稳定（货物≈55%/服务≈41%/工程≈4%）
3. **离群值**：缩尾 99% 后负效应仍显著；中位数版不显著（如实报告分歧）

## 六、结论与下一步

- 合同级数据把 v2.x 的三个候选解释（估计量、测量噪声、样本）测了两个：
  估计量不是问题（v2.1），测量噪声大幅缓解但识别变异仍受限（v3.0）
- 在可识别窗口内：**改革被实施，竞争未改善**；均值指标的显著负效应待定性
- v4.0 方向：合同级回归（控制合同金额/类型/CPV/买方类型 + 国家×年 FE），
  把分析从"国家-年汇总"下沉到"合同级"，用合同特征吸收组成变异；
  更长窗口（2013-2023 已下载 2022/2023 可扩展）
